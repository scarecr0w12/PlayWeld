# PlayWeld Unreal editor bridge

First-party source under the repository Apache-2.0 license. This module belongs to PlayWeld and uses Unreal's own editor, JSON and HTTP modules. It has no CodeFizz dependency, model provider, AI inference, account login or licensing service.

**Live-verified scope:** Windows/Unreal 5.8.3 compilation, authenticated MCP identity and bounded scene inspection, owned-actor spawn/transform/delete, active-viewport PNG capture and console access enforcement. Native PlayWeld tools also installed the source and paired the real editor. Broader scene/asset authoring, lifecycle recovery, packaged deployment and other engine/OS versions remain open. This is an editor bridge with bounded operations, not complete game-art acceptance.

The module is opt-in and excluded from game runtime targets. Without a valid user-scoped DPAPI credential at the selected Unreal Project's `Saved/PlayWeldEditor/session-token.dpapi`, it exposes no endpoint. The decrypted credential stays in editor memory; `session.json` contains only public endpoint/Project identity metadata. Managed pairing retains the matching bearer credential through PlayWeld's encrypted MCP store rather than source, command arguments or plaintext Project files.

The endpoint binds IPv4 loopback, rejects browser origins and unexpected hosts, requires bearer authentication, bounds request size and runs handlers only on the editor thread. MCP requests use `/mcp`; identity reports the exact `.uproject` path. Existing PlayWeld Project scoping, tool classification, permission checks and evidence persistence remain authoritative. Actual tests rejected missing/invalid credentials, browser origins, foreign-Project invocation and Restricted-mode console execution.

Through `tool/call`, run `engine/editor-bridge-install` with `{ "projectFile": "game/YourGame/YourGame.uproject" }`, using the exact Project-relative file. It preserves existing plugin choices and rejects locally modified owned source. Build the Unreal editor target with the installed compiler/engine and open the Project. Then call `engine/editor-bridge-connect` with the same file. It validates the actual editor's identity, protects credentials and binds the existing engine connector. Source installation is not compilation; the install result explicitly reports `editorBuildRequired`.

The five MCP tools are `get_project_context`, `inspect`, `edit_scene`, `screenshot` and `console`. Initial scene edits support spawning StaticMeshActor, PointLight and CameraActor and transforming/deleting actors tagged `PlayWeldOwned`; they do not save the level. Full console access can perform broader authoring operations and remains classified destructive. Model routing and approvals stay in the platform service; server-initiated model calls are disabled for managed connections.
