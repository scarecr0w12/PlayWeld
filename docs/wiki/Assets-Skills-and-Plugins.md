# Assets, skills and plugins

Setup is separate from successful generation or engine import. Begin with inspection and a disposable Project; learning the UI needs no paid job.

## Review assets

**PlayWeld > Build & Connect > Assets** separates **Library**, **Preview**, **Generate** and **Jobs**. Account and advanced generation controls expand separately.

Submission, completion, download, review and import are distinct. Inspect dimensions, scale/axes, topology, materials, rig/animation, provenance and license. Human asset/review approval is required before asset/import; review is user-only. Import stays inside the Project, preserves provenance and uses a fresh name on collision.

A preview does not prove collision or gameplay suitability. Fixture tests and selected live artifacts do not certify every provider pipeline or production quality. Generation may cost money; review the provider/account/operation and access policy first. See [review/import workflow](https://github.com/scarecr0w12/PlayWeld/blob/main/docs/WORKFLOW_COOKBOOK.md#review-an-asset-before-importing-it).

## Skills and roles

Under **Configure & Extend > Skills**, inspect origin, scope, enabled state and **Read guide**. Agent Skills use SKILL.md; Project instructions use AGENTS.md. Skills provide instructions, not installed software or extra authority. Roles set responsibility and tool/access ceilings.

Specify editable source, units, target engine and evidence when requesting art. A bundled skill is not live acceptance of its tool.

## Plugin types

**Plugins** separates **Installed**, **Install**, **Selected plugin** and **Modules**. Platform plugins differ from compiled Theia extensions and VS Code-compatible editor plugins.

Review privileges/compatibility before installation. Project activation differs from platform installation; removal can affect dependent tasks/tools. Durable Project/task/router state stays in the service.

See [integration contracts](https://github.com/scarecr0w12/PlayWeld/blob/main/docs/INTEGRATION_GUIDE.md) and [skill coverage](https://github.com/scarecr0w12/PlayWeld/blob/main/docs/GAME_DEVELOPMENT_SKILLS.md).
