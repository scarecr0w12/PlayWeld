# PlayWeld handbook

PlayWeld is a free, open-source desktop workspace for game development. Its Eclipse Theia Control Room brings Project files, design records, conversations, supervised agent work and tool connections together. A local platform service owns the operational records.

[Watch the demo](https://playweld.com/#demo) · [Download testing builds](https://github.com/scarecr0w12/PlayWeld/releases)

## Work on your game

Use [notes and discussions](https://github.com/scarecr0w12/PlayWeld/wiki/Notes-and-Discussions) for design, [tasks and impact](https://github.com/scarecr0w12/PlayWeld/wiki/Tasks-and-Impact) for supervised changes and [Knowledge and search](https://github.com/scarecr0w12/PlayWeld/wiki/Knowledge-and-Search) for cited material. Configure [models, privacy and cost](https://github.com/scarecr0w12/PlayWeld/wiki/Models-Privacy-and-Cost) before sending requests. Connect installed engines through [engine and tool integrations](https://github.com/scarecr0w12/PlayWeld/wiki/Engine-and-Tool-Integrations) and review [assets and extensions](https://github.com/scarecr0w12/PlayWeld/wiki/Assets-Skills-and-Plugins) before adding content.
