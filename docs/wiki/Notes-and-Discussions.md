# Notes and discussions

Use Markdown under Project docs/ for durable notes and Discussion Board for exploration, questions, blockers and decisions. There is no standalone Notes page in the current menu.

## Write a useful note

Create a focused file in the IDE. Describe the game rule, affected system, open question and evidence needed; link the relevant native file or test. Save it before expecting search to find it.

The file is authoritative. An index is derived data and a model answer is not an adopted rule. Use [Knowledge](https://github.com/scarecr0w12/PlayWeld/wiki/Knowledge-and-Search) to retrieve citations after indexing.

## Discuss and decide

Open **PlayWeld > Plan & Collaborate > Discussion Board**, select the Project and expand **New thread**. Enter title, kind, tags, first message and message type. Quick views **All**, **Open**, **Questions**, **Blockers** and **Decisions** help find it later.

Write evidence as an observation with version, fixture, operation and result. Resolve settled threads; archiving and deletion are separate actions.

Posting a decision-type message does not bind canon. Review the statement, choose **Mark as binding decision** and its explicit synchronization flow, then inspect document proposal/status and the generated docs/decisions record. Preserve provenance and conflicts.

If synchronization is pending, inspect maintenance tasks and approvals before retrying. On conflict, preserve existing text; repeatedly posting is not a repair.

The [decision workflow](https://github.com/scarecr0w12/PlayWeld/blob/main/docs/WORKFLOW_COOKBOOK.md#bind-a-discussion-decision-into-a-durable-document) demonstrates a synthetic UI exercise, not unrestricted autonomous reconciliation.
