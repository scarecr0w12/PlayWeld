# Workspace and navigation

Start in **Project Home**, confirm service connectivity and open the intended Project. Files, terminals, source control and other Theia IDE views coexist with PlayWeld screens.

## PlayWeld menu

| Group              | Destinations                                                                         |
| ------------------ | ------------------------------------------------------------------------------------ |
| Direct entries     | Project Home; Create Project...                                                      |
| Plan & Collaborate | Chat; Swarm; Discussion Board; Knowledge & Canon                                     |
| Build & Connect    | Assets; Engine; Creative Tools; Tool Connections                                     |
| Configure & Extend | Models & Routing; Skills; Plugins; PlayWeld Settings; IDE Settings; Open IDE View... |
| Review & Maintain  | Backups; Audit Log; Updates                                                          |

These are current menu labels. Destination tabs may use shorter names: **Knowledge**, **DCC Tools**, **Connections** or **Audit**. Project Home cards also provide routes.

## Inside a page

Check that page's Project selector. Section navigation and expandable advanced controls hide unrelated forms until selected. Knowledge separates **Index status**, **Search**, **Canon records** and **Settings**; Swarm separates **Agents**, **Approvals**, **Integrations** and **Resource locks**.

**PlayWeld Settings** controls platform behavior; **IDE Settings** controls the shell. A task card is service state, an editor document is a file and a connected tool is transport state. Navigation does not prove execution.

Closing a window can leave work running: window.closeBehavior defaults to continue. Check service status rather than inferring shutdown.

Use the [Control Room handbook](https://github.com/scarecr0w12/PlayWeld/blob/main/docs/CONTROL_ROOM_HANDBOOK.md) for individual controls/screenshots and [troubleshooting](https://github.com/scarecr0w12/PlayWeld/wiki/Troubleshooting) if an action remains unavailable.
