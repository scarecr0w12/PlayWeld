# PlayWeld 0.23.0 testing prerelease

This testing build includes the approved MCP discovery and Requests keyboard fixes, plus the accumulated changes since the previous public testing release.

- MCP tool discovery now respects tool-list invalidation during concurrent requests, including the promise settlement window, with bounded retries and recovery after failures.
- Requests restores safe keyboard focus when opened or after a response resolves. The inspector stays empty until another request is deliberately selected; the next approval is never automatically selected or focused. Drafts survive the verified refresh/disconnect recovery journey.
- Accumulated changes include grouped Requests, audit export/retention, plugin settings upgrades, service log retention, SQLite diagnostics and verified Project recovery snapshots, lexical-index recovery, and dependency/security corrections. The detailed notes distinguish implementation from acceptance that remains open.

The complete task details, validation, compatibility notes and limitations are preserved in the attached `PlayWeld-0.23.0-release-notes.md`, the versioned source notes and `CHANGELOG.md`.

Windows x64 NSIS and Linux x64 AppImage/DEB packages are provided for manual testing. Inspect `gamecrafter-release.json` and `SHA256SUMS.txt` for the exact source commit, compatibility and file hashes. Signing status is stated in the manifest; checksums establish integrity and do not establish publisher identity. The Windows executable is not claimed to have Authenticode publisher signing.

This is a **prerelease**, excluded from the stable automatic update channel. Source/browser tests and packaged-content checks do not certify installer upgrade/uninstall/rollback, comprehensive accessibility, every live provider/engine integration or ordinary-profile preservation for this version. Use isolated test data and retain backups when testing upgrades.
